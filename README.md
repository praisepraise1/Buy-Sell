# Buy&Sell 👟

Buy&Sell is a modern, responsive e-commerce website designed for buying and selling footwear online. It features a clean and user-friendly interface, allowing customers to browse products, add items to their cart, and enjoy a seamless shopping experience.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and clean user interface
- Product listing section
- Shopping cart with item count
- Add-to-cart functionality
- Interactive user experience using JavaScript
- Fast and lightweight performance
- Built with Tailwind CSS CDN

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- Vanilla JavaScript
